# 宫格切图桌面应用设计方案

## 1. 项目目标

开发一款面向 AI 宫格图的本地桌面切图工具。用户可以导入 2K、3K、4K 图片，自动识别常见宫格布局，也可以手动校准切割边界；最终使用原始图片和原像素坐标导出，确保切割过程不缩放、不模糊、不锐化，默认以 PNG 无损格式保存。

首版支持 macOS 和 Windows，同时覆盖单张精调与多图批量处理。

## 2. 核心原则

1. 图片只在用户本机处理，不上传服务器。
2. 预览图只用于界面显示，绝不作为导出源。
3. 所有切割边界最终转换为原图整数像素坐标。
4. 默认输出 PNG，避免二次有损编码。
5. 自动识别只负责提供可靠的初始切割线，最终结果允许人工精确校准。
6. 对无法可靠识别的布局明确提示，不伪造高置信度结果。

## 3. 产品范围

### 3.1 V1 包含

- macOS、Windows 桌面安装包。
- 拖拽或文件选择导入单张、多张图片。
- 导入 PNG、JPEG、WebP。
- 自动识别常见规则宫格布局。
- 内置布局模板选择。
- 添加、删除、拖动、锁定和精确输入切割线。
- 100% 原图级预览检查。
- 自定义模板保存与复用。
- 单张导出。
- 统一模板批量导出。
- 逐图自动识别批量导出。
- 默认 PNG 无损输出，可选 JPEG、WebP 及质量参数。
- 任务进度、待确认状态、失败重试和结果统计。
- 中文文件名和中文目录支持。

### 3.2 V1 不包含

- 云端账号、图片上传与同步。
- 手机端。
- 联网大模型识别。
- 图片滤镜、修复、放大等编辑能力。
- PSD 等专业工程文件。
- 任意复杂无缝拼图的全自动语义分割。

### 3.3 后续候选能力

- TIFF 等更多专业格式。
- 可选的本地视觉模型或联网 AI 辅助识别。
- 更多社区或用户共享模板。
- 自动更新和应用内更新说明。

## 4. 技术路线

采用 Tauri 2 + React + TypeScript + Rust：

- Tauri 负责桌面窗口、系统文件选择、目录权限和跨平台安装包。
- React + TypeScript 负责三栏工作台、图片预览、切割线交互和任务状态。
- Rust 负责原图读取、方向修正、像素坐标裁切、格式编码、元数据处理和批量任务执行。
- 应用不依赖远端业务服务器，离线即可完成核心功能。

选择 Tauri 而非 Electron，是为了降低安装包和运行内存占用，并让图像处理逻辑直接运行在 Rust 本地层。选择桌面应用而非纯网页，是为了获得稳定的文件夹权限、批量读写能力和大图内存控制。

## 5. 系统架构

### 5.1 前端界面层

职责：

- 管理导入任务列表。
- 请求和显示缩放预览图。
- 显示识别结果、置信度和切割区域。
- 支持切割线的鼠标及键盘交互。
- 展示导出参数、进度、错误和最终统计。
- 将用户确认的布局以标准化坐标提交给 Rust 层。

前端不直接编码最终图片，也不从 Canvas 导出最终切图。

### 5.2 图像处理层

职责：

- 读取原图尺寸、格式、EXIF 方向、ICC、DPI 等信息。
- 生成仅供界面使用的缩小预览图。
- 生成用于接缝分析的低分辨率分析图。
- 将标准化切割线换算为原图整数像素坐标。
- 校验所有输出区域完整覆盖目标画布且无重叠、无遗漏。
- 从原始解码像素裁切并编码输出。
- 执行批量任务，隔离单张图片错误。

### 5.3 本地配置层

只保存：

- 最近使用的导出目录。
- 默认导出格式与质量参数。
- 用户创建的自定义布局模板。
- 非敏感的界面偏好。

不复制、上传或长期缓存用户的原始图片。临时预览缓存由应用管理并可自动清理。

## 6. 画质保证策略

### 6.1 预览与导出分离

界面加载缩小预览以保证操作流畅。用户在预览上的切割线以 0 到 1 的标准化坐标保存，例如垂直线位于图片宽度的 0.5。导出时再根据原图实际宽高换算为整数像素坐标。

最终导出始终重新读取原始文件，不使用预览图或浏览器 Canvas 的像素结果。

### 6.2 格式规则

- PNG：默认选项，裁切后以无损方式编码，不发生额外有损压缩。
- JPEG：用户主动选择时启用，显示质量参数，并明确提示会重新编码。
- WebP：用户主动选择时启用，可选择无损或有损模式；有损模式显示质量参数。

将 JPEG 原图导出为 PNG 不能恢复原图生成前已经损失的信息，但可以避免切割阶段再次引入 JPEG 有损压缩。

### 6.3 色彩与方向

- 读取并正确应用 EXIF 方向。
- 尽可能保留 ICC 色彩配置、DPI 和必要的 EXIF 信息。
- 不主动改变色彩空间。
- 不执行缩放、锐化、降噪、滤镜或自动增强。

### 6.4 像素覆盖

切割区域使用半开区间表达，确保相邻区域共享同一条边界但不会重复像素。所有区域联合后必须完整覆盖目标图片范围，不允许出现一像素空隙、重叠或零尺寸区域。

## 7. 自动识别与布局模板

### 7.1 自动识别流程

1. 读取图片宽高并生成缩小分析图。
2. 扫描可能的横向和纵向接缝。
3. 综合接缝强度、接缝两侧内容连续性、区域比例和常见模板进行评分。
4. 选择最高评分布局并生成初始切割线。
5. 显示布局名称、切割区域和置信度。
6. 低置信度任务标记为“待确认”，不直接进入自动导出。

规则无缝宫格通常可以结合常用比例和接缝特征获得有效初始结果。任意不规则且无明显视觉接缝的拼图不承诺 100% 自动识别，必须允许人工确认。

### 7.2 首版内置模板

- 2 × 2 四宫格。
- 3 × 3 九宫格。
- 1 × 2、2 × 1。
- 1 × 3、3 × 1。
- 1 × 4、4 × 1。
- 上一张 + 下两张。
- 上两张 + 下一张。
- 左一张 + 右两张。
- 左两张 + 右一张。
- 自定义横线、竖线组合。

### 7.3 置信度规则

- 高：可直接加入导出队列，但界面仍展示结果。
- 中：建议用户浏览确认。
- 低：强制进入“待确认”状态，用户确认或修改后才能导出。

具体评分阈值在实现与样本测试阶段校准，不作为用户可配置项。

## 8. 手动校准

- 拖动任意横向或纵向切割线。
- 双击画布增加切割线。
- 选中切割线后删除。
- 直接输入原图像素坐标。
- 方向键移动 1 像素。
- Shift + 方向键移动 10 像素。
- 锁定切割线，防止误操作。
- 放大、缩小、适应窗口和 100% 原图查看。
- 显示每个输出区域的编号和实际像素尺寸。
- 将已确认布局保存为自定义模板。

拖动过程中使用预览坐标保证流畅；拖动结束后显示换算得到的原图整数像素坐标。

## 9. 主界面设计

采用已确认的三栏专业工作台。

### 9.1 左栏：图片任务

- 导入图片和导入文件夹入口。
- 单张、多张任务列表。
- 每张图片显示缩略图、名称、尺寸和状态。
- 状态包括：分析中、已识别、待确认、可导出、导出中、成功、失败。
- 支持筛选待确认和失败任务。

### 9.2 中栏：预览画布

- 深色背景，突出图片和高亮切割线。
- 显示当前图片尺寸、缩放比例和识别结果。
- 切割区域按从左到右、从上到下编号。
- 支持拖动、添加、删除、锁定切割线。
- 支持适应窗口、100%、放大和缩小。

### 9.3 右栏：切割与导出设置

- 布局模板选择。
- 自动识别结果与置信度。
- 切割线或区域的精确像素信息。
- 输出格式和质量设置。
- 输出目录和命名规则。
- 预计输出数量与尺寸。
- 导出当前图片和批量导出入口。

## 10. 导出规则

### 10.1 默认目录

默认在原图所在目录创建“原文件名_切图”文件夹。用户可以修改为统一输出目录。

### 10.2 文件命名

默认命名为：

- `原文件名_01.png`
- `原文件名_02.png`
- `原文件名_03.png`

编号顺序为从左到右、从上到下。若文件已存在，默认追加递增序号，不覆盖已有文件。

### 10.3 单张导出

导出前显示输出数量、每块像素尺寸、格式和目录。完成后可直接打开输出文件夹。

### 10.4 批量模式

统一模板模式：

- 将当前确认布局以标准化宽高比例应用到所选图片。
- 允许源图片分辨率不同。
- 若图片长宽比差异超过安全阈值，则标记为待确认，避免错误套用。

逐图识别模式：

- 每张图片独立执行自动识别。
- 高置信度图片进入可导出队列。
- 中低置信度图片进入待确认列表。
- 所有待确认图片处理完毕后统一开始导出，或由用户明确选择只导出已确认项。

## 11. 错误处理

- 不支持或损坏的文件显示明确原因。
- 单张图片失败不终止整个批次。
- 失败任务保留在列表，可修改设置后重试。
- 导出目录不可写时，暂停相关任务并要求重新选择目录。
- 文件重名时不静默覆盖。
- 内存紧张时缩小预览缓存并改为顺序导出，不降低最终输出分辨率。
- 应用异常退出后不承诺恢复未完成任务，但已成功写入的文件保持有效。

## 12. 性能设计

- 原图解码、识别和导出在后台线程执行，不阻塞界面。
- 预览图按窗口所需尺寸生成并缓存。
- 拖动切割线只更新矢量覆盖层，不重复解码图片。
- 批量导出设置受控并发数，避免同时解码过多 4K 图片。
- 写入文件时先输出到同目录临时文件，成功后再原子改名，减少半成品文件。

## 13. 验收标准

### 13.1 像素正确性

- 输入 3840 × 2160 的标准 2 × 2 图片，输出四张必须各为 1920 × 1080。
- 将 PNG 输出按原坐标重新拼合后，解码像素必须与应用裁切前的原始解码像素完全一致。
- 手动输入和拖动得到的导出坐标误差为 0 像素。
- 所有输出块联合后无遗漏、无重叠。
- PNG 输出不得发生缩放、模糊、锐化或额外颜色处理。

### 13.2 功能正确性

- 常用内置模板能够正确生成切割区域。
- 自动识别不确定时明确进入待确认状态。
- 自定义模板可保存并再次应用。
- 单张失败不影响批次中的其他图片。
- 重名文件不会被静默覆盖。
- EXIF 方向图片导出方向正确。

### 13.3 跨平台与兼容性

- macOS 和 Windows 均可完成安装、导入、预览、校准和导出。
- 中文文件名、中文目录和空格路径均能正常处理。
- PNG、JPEG、WebP 输入均有覆盖测试。

### 13.4 性能体验

- 单张 4K 图片可流畅预览。
- 拖动切割线时不重新解码原图。
- 批量处理过程中界面保持响应。
- 内存保护策略不降低最终输出分辨率。

## 14. 测试策略

### 14.1 Rust 单元测试

- 标准化坐标到原图像素坐标的换算。
- 半开区间切割区域生成。
- 区域完整覆盖、无重叠、无零尺寸校验。
- 文件命名和重名处理。
- 格式参数校验。

### 14.2 图像回归测试

- 使用已知像素图案执行裁切并逐像素对比。
- 测试奇数宽高图片的边界分配。
- 测试透明 PNG、JPEG、WebP 和 EXIF 旋转图片。
- 测试 ICC、DPI 等元数据的保留策略。

### 14.3 前端交互测试

- 导入、任务选择和状态筛选。
- 切割线添加、删除、拖动、锁定和键盘微调。
- 缩放后坐标换算一致性。
- 低置信度任务确认流程。
- 单张与批量导出设置。

### 14.4 跨平台人工验收

- 在当前支持的 macOS 和 Windows 版本上分别安装测试。
- 使用包含中文、空格和长文件名的路径进行导入与导出。
- 使用真实 2K、3K、4K AI 宫格图验证识别与手动校准体验。

## 15. 建议实施阶段

1. 项目骨架与跨平台文件导入。
2. Rust 原像素裁切引擎及像素回归测试。
3. 三栏工作台与预览画布。
4. 手动切割线交互和模板系统。
5. 自动识别与置信度机制。
6. 单张、批量导出及错误恢复。
7. 元数据、性能和跨平台兼容性完善。
8. macOS、Windows 安装包与最终验收。

每个阶段都应保持可运行、可测试，并优先保证像素正确性，再增加自动化和批量效率。
